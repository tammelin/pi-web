# Skill reference navigation — PR screenshots

Public screenshots for the `fix/skill-reference-navigation` contribution to `agegr/pi-web`. This assets-only branch keeps image binaries out of the upstream feature diff.

All images show synthetic skills in an isolated development instance. No real conversations, credentials or production data are included.

- `skill-reference-before.png`: Skills overview on unmodified upstream `f83b1a5` (v0.12.1).
- `skill-reference-before-404.png`: following the overview's relative document link on that version opens an application-relative URL in a new tab and returns 404.
- `skill-reference-after-desktop.png`: the linked document opens in the skill's detail pane; the sidebar selection remains and the header offers Back and Skill overview.
- `skill-reference-after-mobile.png`: the same reference pane at a 390px browser viewport.

The desktop images are cropped to Settings. The after images hide only the Next.js development indicator during capture.
